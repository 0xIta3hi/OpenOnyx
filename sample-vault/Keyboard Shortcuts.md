# Keyboard Shortcuts

Quick reference for all keyboard shortcuts in OpenObsidian.

## General

| Shortcut | Action |
|----------|--------|
| `Ctrl+P` | Open Command Palette |
| `Ctrl+Shift+F` | Search entire vault |
| `Ctrl+F` | Find/replace in current note |
| `Ctrl+G` | Toggle graph view |
| `Ctrl+B` | Toggle sidebar |
| `Ctrl+N` | Create new note |
| `Ctrl+S` | Save current note |
| `Ctrl+W` | Close current tab |

## Editor

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+/` | Toggle comment |
| `Tab` | Indent |
| `Shift+Tab` | Outdent |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+Click` | Follow wiki link |
| `Ctrl+Enter` | Open link in new tab |

## Graph View

| Shortcut | Action |
|----------|--------|
| `Ctrl+G` | Toggle graph |
| Click node | Navigate to note |
| Drag | Pan view |
| Scroll | Zoom in/out |

## Tips

- Use `[[` to trigger link autocomplete
- Type `>` then `[!type]` for callouts
- Use `#` for tags (autocomplete coming soon)
