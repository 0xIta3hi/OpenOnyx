# 🗣️ Communication Skills

## Active Listening

1. Give full attention
2. Don't interrupt
3. Reflect back what you heard
4. Ask clarifying questions

## Clear Speaking

- Be concise
- Structure thoughts: situation → action → result
- Avoid filler words
- Pause for effect

## Written Communication

### Emails
- Clear subject line
- Main point first
- Bullet points for clarity
- Clear call to action

### Documentation
See [[Code Review Checklist]] for technical writing.

## Non-Verbal

- Eye contact
- Open posture
- Nodding
- Facial expressions

## Difficult Conversations

- Focus on facts
- Use "I" statements
- Seek understanding
- Find common ground
