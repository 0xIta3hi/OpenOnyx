# 💵 Budgeting Basics

## 50/30/20 Rule

| Category | % | Examples |
|----------|---|----------|
| Needs | 50% | Rent, food, utilities |
| Wants | 30% | Dining, entertainment |
| Savings | 20% | Emergency fund, investments |

## Zero-Based Budget

Every dollar gets a job:

```
Income: $5,000
- Rent: $1,500
- Food: $500
- Utilities: $200
- Transportation: $300
- Savings: $1,000
- Entertainment: $300
- Misc: $200
= $0 remaining
```

## Tracking Methods

1. **Spreadsheet**: Manual, customizable
2. **Apps**: Mint, YNAB, Copilot
3. **Envelope system**: Cash-based

## Emergency Fund

Target: 3-6 months of expenses

Priority order:
1. $1,000 starter emergency fund
2. Pay off high-interest debt
3. Build to 3-6 months
