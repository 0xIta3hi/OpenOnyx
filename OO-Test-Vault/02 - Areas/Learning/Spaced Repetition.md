# 🔄 Spaced Repetition

## Concept

Review material at increasing intervals to optimize retention.

## The Forgetting Curve

```
Memory
  │
  │\
  │ \
  │  \___________
  │
  └─────────────── Time
```

Each review "resets" the curve.

## Optimal Intervals

| Review | Interval |
|--------|----------|
| 1st | 1 day |
| 2nd | 3 days |
| 3rd | 7 days |
| 4th | 14 days |
| 5th | 30 days |

## Tools

- **Anki**: Most powerful, customizable
- **RemNote**: Note-taking + SRS
- **Quizlet**: Simple, social

## Best Practices

1. **Atomic cards**: One idea per card
2. **Use images**: Visual memory
3. **Active recall**: Don't peek
4. **Consistent reviews**: Daily habit
