# 📄 Resume Writing

## Structure

1. **Header**: Name, contact, links
2. **Summary**: 2-3 lines (optional)
3. **Experience**: Reverse chronological
4. **Skills**: Technical + soft
5. **Education**: Degrees, relevant courses

## STAR Method for Bullets

- **S**ituation: Context
- **T**ask: Your responsibility
- **A**ction: What you did
- **R**esult: Measurable outcome

### Example

> "Led migration of legacy system to microservices architecture ([[Microservices Architecture]]), reducing deployment time by 75% and improving system reliability to 99.9% uptime."

## Tips

### Do
- Use action verbs
- Quantify achievements
- Tailor to job description
- Keep to 1-2 pages

### Don't
- Use "I" statements
- Include irrelevant experience
- Use generic descriptions
- Have typos

## ATS Optimization

- Use standard headings
- Include keywords from job posting
- Avoid tables/columns
- Submit as PDF
