# 📲 Mobile UI Patterns

## Navigation Patterns

### Tab Bar
Best for 3-5 main sections. Used by most apps.

### Drawer Navigation
Good for apps with many sections or settings.

### Stack Navigation
Standard push/pop for hierarchical content.

## Common UI Components

### Cards
```
┌─────────────────────────┐
│  🖼️  Image             │
├─────────────────────────┤
│  Title                  │
│  Description text...    │
│  [Action] [Action]      │
└─────────────────────────┘
```

### Lists
- Flat lists for simple data
- Section lists for grouped data
- Swipeable rows for actions

### Forms
- Floating labels
- Inline validation
- Keyboard-aware scroll

## Gestures

| Gesture | Use Case |
|---------|----------|
| Tap | Selection, navigation |
| Swipe | Delete, reveal actions |
| Long press | Context menu |
| Pinch | Zoom |
| Pull down | Refresh |
