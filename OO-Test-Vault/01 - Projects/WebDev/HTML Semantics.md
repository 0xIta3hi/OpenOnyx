# 📄 HTML Semantics

## Why Semantic HTML?

- Accessibility
- SEO
- Maintainability
- Screen readers

## Key Elements

| Element | Purpose |
|---------|---------|
| `<header>` | Page/section header |
| `<nav>` | Navigation |
| `<main>` | Main content |
| `<article>` | Self-contained content |
| `<section>` | Thematic grouping |
| `<aside>` | Related content |
| `<footer>` | Page/section footer |

## Forms

```html
<label for="email">Email</label>
<input id="email" type="email" required>
```
