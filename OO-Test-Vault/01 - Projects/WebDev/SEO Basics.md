# 🔍 SEO Basics

## On-Page SEO

### Meta Tags
```html
<title>Page Title - Site Name</title>
<meta name="description" content="Page description">
```

### Headings
- One H1 per page
- Logical hierarchy

### Content
- Quality content
- Keywords naturally
- Internal linking

## Technical SEO

- Fast loading ([[Performance Optimization]])
- Mobile-friendly
- HTTPS
- XML sitemap
- robots.txt

## Off-Page SEO

- Backlinks
- Social signals
- Brand mentions
