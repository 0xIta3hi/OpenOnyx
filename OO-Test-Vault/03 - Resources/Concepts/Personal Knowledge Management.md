# 📝 Personal Knowledge Management

## What is PKM?

A system for capturing, organizing, and retrieving information.

## Components

### Capture
- Quick notes
- Highlights
- Voice memos
- Screenshots

### Organize
- [[PARA Method]]
- Tags
- Links
- Folders

### Retrieve
- Search
- [[Backlinks]]
- Graph view
- Maps of Content

### Create
- Connect ideas
- Generate insights
- Produce content

## Tools

- **Obsidian**: Markdown, local, linking
- **Notion**: Database, flexible, cloud
- **Roam**: Outliner, daily notes
- **Logseq**: Open-source, outliner
