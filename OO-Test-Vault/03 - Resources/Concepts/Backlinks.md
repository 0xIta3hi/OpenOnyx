# 🔗 Backlinks

## What Are Backlinks?

References to the current note from other notes.

## Why They Matter

- Discover connections
- Navigate bidirectionally
- Build knowledge graph
- Surface related ideas

## Using Backlinks

In Obsidian:
1. Open backlinks panel
2. See all references
3. Click to navigate
4. See unlinked mentions

## Best Practices

- Use specific link text
- Link liberally
- Check backlinks when writing
- Convert unlinked mentions
