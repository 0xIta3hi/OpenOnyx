# 🧠 Active Recall

## What Is It?

Testing yourself on material rather than passively reviewing.

## Why It Works

- Strengthens memory pathways
- Identifies knowledge gaps
- More efficient than re-reading

## Techniques

### Flashcards
Create question/answer pairs.
See [[Spaced Repetition]] for optimal review.

### Practice Problems
Actually work through problems without looking at solutions.

### Teaching
Explain concepts to others (or rubber duck).

### Blank Page Method
Write everything you remember, then check.

## Implementation

1. Read/learn material
2. Close the source
3. Recall from memory
4. Check and correct
5. Repeat
