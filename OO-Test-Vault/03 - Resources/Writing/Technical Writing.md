# 📝 Technical Writing

## Principles

1. **Clarity**: Be precise
2. **Brevity**: Cut unnecessary words
3. **Structure**: Use headings, lists
4. **Audience**: Know your reader

## Documentation Types

- README
- API reference
- Tutorials
- How-to guides
- Explanations

## README Template

```markdown
# Project Name

Brief description.

## Installation

## Usage

## Contributing

## License
```
