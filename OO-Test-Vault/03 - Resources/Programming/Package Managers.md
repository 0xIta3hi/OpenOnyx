# 📦 Package Managers

## By Language

| Language | Manager |
|----------|---------|
| JavaScript | npm, yarn, pnpm |
| Python | pip, poetry, conda |
| Ruby | bundler, gem |
| Go | go mod |
| Rust | cargo |

## npm vs yarn vs pnpm

| Feature | npm | yarn | pnpm |
|---------|-----|------|------|
| Speed | OK | Fast | Fastest |
| Disk | More | More | Less |
| Lockfile | package-lock | yarn.lock | pnpm-lock |

## Common Commands

```bash
# npm
npm install
npm install pkg
npm update

# pip
pip install pkg
pip install -r requirements.txt
pip freeze > requirements.txt
```
