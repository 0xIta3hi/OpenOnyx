# 🐛 Debugging Strategies

## Process

1. **Reproduce** the bug consistently
2. **Isolate** the problem
3. **Identify** the root cause
4. **Fix** the issue
5. **Test** the fix
6. **Document** what you learned

## Techniques

### Rubber Duck Debugging
Explain the problem out loud to find the issue.

### Binary Search
Narrow down by halving the search space.

### Print/Log Debugging
Add strategic logging to trace execution.

## Common Bug Sources

- Off-by-one errors
- Null/undefined references
- Race conditions
- Type mismatches
- State mutations
