# 🔧 Browser DevTools

## Essential Panels

### Elements
Inspect and modify DOM/CSS.

### Console
JavaScript debugging and logging.

### Network
Monitor HTTP requests.

### Sources
Debug JavaScript with breakpoints.

### Performance
Profile runtime performance.

### Application
Storage, service workers, cache.

## Console Tips

```javascript
console.log(variable);   // Basic output
console.table(array);    // Table format
console.time('label');   // Timing
console.trace();         // Stack trace
```

## Network Analysis

- Filter by type
- Check timing waterfall
- Inspect headers
- Replay requests
