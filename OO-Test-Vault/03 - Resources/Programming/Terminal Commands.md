# 💻 Terminal Commands

## File Operations

```bash
# Navigate
cd /path/to/dir
pwd

# List files
ls -la

# Copy/Move/Delete
cp source dest
mv source dest
rm file

# Create
mkdir dirname
touch filename
```

## Text Processing

```bash
# View files
cat file
less file
head -n 10 file
tail -f file

# Search
grep "pattern" file
```
