# 📁 Code Organization

## File Naming

- Use consistent case (camelCase, kebab-case)
- Descriptive names
- Group related files

## Folder Structure

### Feature-Based
```
src/
├── features/
│   ├── auth/
│   ├── users/
│   └── posts/
└── shared/
```

### Type-Based
```
src/
├── components/
├── services/
├── utils/
└── types/
```

## Principles

1. Colocation: Keep related code together
2. Separation of concerns
3. Single responsibility
4. Easy navigation
