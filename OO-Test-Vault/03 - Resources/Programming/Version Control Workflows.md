# 🔀 Version Control Workflows

## Git Flow

- main: Production
- develop: Integration
- feature/*: New features
- release/*: Release prep
- hotfix/*: Production fixes

## GitHub Flow

Simplified:
1. Create branch
2. Make changes
3. Open PR
4. Review
5. Merge to main
6. Deploy

## Trunk-Based

- Short-lived branches
- Frequent merges
- Feature flags

## Best Practices

- Small, focused commits
- Meaningful commit messages
- Pull before push
- Review before merge
