# 📁 PARA Method

## The Four Categories

### Projects
Active work with a deadline or outcome.

### Areas
Ongoing responsibilities with standards.

### Resources
Reference material for interests/hobbies.

### Archives
Inactive items from other categories.

## This Vault Structure

```
00 - Inbox
01 - Projects
02 - Areas
03 - Resources
04 - Archive
```
