# 📅 Time Blocking

## What Is It?

Assign specific tasks to specific time blocks.

## Why It Works

- Reduces decision fatigue
- Creates boundaries
- Increases [[Deep Work Notes|deep work]] time
- Provides structure

## My Schedule Template

| Time | Block |
|------|-------|
| 6:00-7:00 | Morning routine |
| 7:00-9:00 | Deep work #1 |
| 9:00-10:00 | Email/Slack |
| 10:00-12:00 | Meetings |
| 12:00-1:00 | Lunch |
| 1:00-3:00 | Deep work #2 |
| 3:00-4:00 | Admin tasks |
| 4:00-5:00 | Planning/Review |
