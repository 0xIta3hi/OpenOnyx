# 🎲 Probability Basics

## Fundamentals

**Probability**: P(A) = favorable outcomes / total outcomes

Range: 0 ≤ P(A) ≤ 1

## Key Rules

### Addition Rule
P(A or B) = P(A) + P(B) - P(A and B)

### Multiplication Rule
P(A and B) = P(A) × P(B|A)

### Complement
P(not A) = 1 - P(A)

## Distributions

### Normal Distribution
Bell curve, mean = median = mode

### Binomial
Fixed trials, two outcomes (success/failure)

### Poisson
Count of events in fixed interval
