# ∫ Calculus Basics

## Derivatives

Rate of change.

**Common derivatives**:
- d/dx(x^n) = nx^(n-1)
- d/dx(e^x) = e^x
- d/dx(ln x) = 1/x

## Integrals

Area under curve.

**Common integrals**:
- ∫x^n dx = x^(n+1)/(n+1) + C
- ∫e^x dx = e^x + C
